# 공강맞춤 웹 데모

PRD와 디자인 문서를 바탕으로 만든 반응형 팀 프로젝트 관리 웹 데모입니다.

## 실행

- `index.html`을 브라우저에서 열거나, 이 폴더에서 `python -m http.server 4173`을 실행한 뒤 `http://localhost:4173`에 접속하세요.
- 첫 화면에는 샘플 팀 프로젝트가 표시됩니다. 업무 생성, 담당자별 보기, 초대 링크, 상태 이력, 리포트 흐름을 둘러볼 수 있습니다.

## 데모 데이터와 범위

- 프로젝트와 업무는 현재 브라우저의 `localStorage`에 저장됩니다.
- 로그인과 회원가입 화면은 흐름을 보여주는 데모입니다. 계정 인증은 처리하지 않습니다.
- 이메일 발송, 서버 동기화, 여러 기기 간 초대 참여는 백엔드가 연결되지 않아 동작하지 않습니다. 마감 알림은 화면 배너로 확인할 수 있습니다.
- 리포트의 PDF 내보내기는 브라우저 인쇄 창을 열며, 인쇄 대상을 PDF로 선택하면 저장할 수 있습니다.
- 기여도를 점수화하거나 팀원을 순위로 표시하지 않습니다.
